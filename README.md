This template is based on [Dr. Jason K. Moore's work](https://github.com/moorepants/icsc2024).

Instructions
- Go to this template repository's page on GitHub.
- Click the green "Use this template" button to create a new repository.
- Use `git clone` to download a local copy of this repository.
- Check the `conf_info.tex` file to make sure the conference information is updated.
- The rendered PDF can be found in the `gh-pages` branch with a path similar to `https://github.com/fenggroup/icsc-template/blob/gh-pages/abstract.pdf?raw=true` in which `fenggroup` should be replaced with your GitHub username, and `icsc-template` should be replaced with the repo name.
